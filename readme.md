# Interactive Computer Components
A simple interactive web project built to practice JavaScript Tabs, Dropdown menus, Modal windows, and Event Handling.

## Features

* Interactive Tabs for computer components
* Dropdown menus for Computer and Network Components
* Modal window for displaying additional information
* Open and close Modal with buttons
* Responsive layout
* Clean and simple user interface

## Technologies

* HTML5
* CSS3
* JavaScript

## What I Practiced

* `classList`
* `addEventListener()`
* Event Handling
* Tabs functionality
* Dropdown functionality
* Modal functionality
* Responsive Design

## AI Transparency

I used AI as a learning assistant during this project to understand concepts, review my approach, and solve development problems. The code and project structure were implemented and practiced by me based on the concepts I learned.
